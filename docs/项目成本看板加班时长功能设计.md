# 项目成本看板加班时长功能设计方案

## 一、需求概述

在项目成本看板页面（`/mzx/project/cost/Board`）的"项目成本"列后面新增"加班时长"列，显示后端返回的 `overtimeHours` 字段。用户点击该列的数字时，弹出模态窗口展示该项目下所有**已确认**的加班记录。

## 二、技术方案

### 2.1 涉及文件

| 文件路径 | 修改类型 | 说明 |
|---------|---------|------|
| `src/views/mzx/projectCostBoard/projectCostBoard.data.ts` | 修改 | 新增"加班时长"列配置 |
| `src/views/mzx/projectCostBoard/index.vue` | 修改 | 新增加班记录弹窗组件和点击事件处理 |
| `src/views/mzx/projectCostBoard/componets/OvertimeRecordModal.vue` | 新增 | 加班记录弹窗组件 |

### 2.2 实现方案

```vue
<template>

```

**脚本部分：**

```typescript
import OvertimeRecordModal from './componets/OvertimeRecordModal.vue';
import { useModal } from '/@/components/Modal';

// 新增加班记录弹窗
const [registerOvertimeModal, { openModal: openOvertimeModal }] = useModal();

/**
 * 查看项目加班记录
 */
function handleOvertimeHours(record) {
  openOvertimeModal(true, {
    projectId: record.projectId,
    projectName: record.projectName,
  });
}
```

#### 2.2.3 新增加班记录弹窗组件（OvertimeRecordModal.vue）

创建 `src/views/mzx/projectCostBoard/componets/OvertimeRecordModal.vue`：

```vue
<template>
  <BasicModal
    v-bind="$attrs"
    @register="registerModal"
    :title="getTitle"
    :showOkBtn="false"
    width="1200px"
    destroyOnClose
  >
    <BasicTable @register="registerTable">
      <template #tableTitle>
        <div>该项目所有加班记录</div>
      </template>
    </BasicTable>
  </BasicModal>
</template>

<script lang="ts" setup>
import { ref, computed, unref } from 'vue';
import { BasicModal, useModalInner } from '/src/components/Modal';
import { BasicTable, useTable } from '/src/components/Table';
import { overtimeList } from '/@/views/mzx/office/components/overtime/OvertimeRecord.api';
import { overtimeColumns } from '/@/views/mzx/office/components/overtime/OvertimeRecord.data';

const projectName = ref('');

const [registerModal] = useModalInner(async (data) => {
  projectName.value = data.projectName;
  // 设置查询参数，按项目ID过滤，只查询已确认的加班记录
  setProps({
    searchInfo: {
      projectId: data.projectId,
      confirmStatus: 1, // 1表示已确认
    },
  });
  reload();
});

const getTitle = computed(() => unref(projectName) + ' -- 加班记录');

const [registerTable, { reload, setProps }] = useTable({
  api: overtimeList,
  columns: overtimeColumns,
  striped: true,
  useSearchForm: false,
  showTableSetting: false,
  clickToRowSelect: false,
  bordered: true,
  showIndexColumn: true,
  tableSetting: { fullScreen: true },
  canResize: false,
  pagination: {
    pageSize: 20,
  },
  immediate: false,
  showActionColumn: false,
});
</script>
```

#### 2.2.4 API 配置

加班记录的列表接口已存在于 `src/views/mzx/office/components/overtime/OvertimeRecord.api.ts`，可以直接复用：

```typescript
// 无需新增 API，直接复用已有的 overtimeList 接口
// 调用时传入 projectId 和 confirmStatus 参数即可过滤该项目的已确认加班记录

export const overtimeList = (params) =>
  defHttp.get({ url: Api.overtimeList, params });
```

### 2.3 数据流程

```
用户点击加班时长数字
    ↓
触发 handleOvertimeHours(record)
    ↓
打开 OvertimeRecordModal 弹窗，传入 projectId
    ↓
弹窗调用 overtimeList API，传入 projectId 和 confirmStatus=1 参数
    ↓
后端返回该项目的所有已确认加班记录
    ↓
表格展示加班记录列表
```

## 三、实现要点

### 3.1 代码复用

1. **列配置复用**：直接导入并使用 `src/views/mzx/office/components/overtime/OvertimeRecord.data.ts` 中的 `overtimeColumns`

2. **API 复用**：直接导入并使用 `src/views/mzx/office/components/overtime/OvertimeRecord.api.ts` 中的 `overtimeList` 接口

3. **组件模式复用**：参考 `ProjectCostDetail.vue` 的实现模式，使用 `BasicModal` + `BasicTable` 组合

### 3.2 性能优化

1. 使用 `destroyOnClose` 确保弹窗关闭时销毁组件，避免数据残留

2. 使用 `immediate: false` 避免表格自动加载数据，等待弹窗打开并传入参数后再加载

3. 分页设置合理的 `pageSize`（20条），避免一次加载过多数据

### 3.3 查询条件

**重要**：只查询已确认的加班记录，通过设置 `confirmStatus: 1` 参数实现：
- `confirmStatus: 0` - 待确认
- `confirmStatus: 1` - 已确认

这样可以确保成本看板中显示的加班时长数据都是经过确认的有效数据。

### 3.4 后端接口要求

确保后端 `/overtime/record/list` 接口支持通过 `projectId` 和 `confirmStatus` 参数过滤数据：

```typescript
// 请求示例
GET /overtime/record/list?projectId=xxx&confirmStatus=1&pageNo=1&pageSize=20

// 响应格式
{
  code: 200,
  result: {
    records: [...],  // 已确认的加班记录列表
    total: 100,      // 总数
  },
  success: true,
}
```
