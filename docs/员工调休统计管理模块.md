# 员工调休统计管理模块

## 功能概述

员工调休统计管理模块用于管理和统计员工的调休情况，包括：

1. **员工调休统计列表**：查看所有员工的调休统计信息（总调休、待确认调休、已确认调休、已使用调休、剩余调休）
2. **加班记录查看**：点击统计数字可查看对应的加班记录详情
3. **调休使用记录查看**：查看员工的调休使用历史
4. **录入调休**：为员工录入调休使用记录，自动校验剩余调休时长

## 子组件详解

### 1. LeaveRecordModal.vue（调休使用记录弹窗）

**功能**：展示员工的调休使用记录列表

**特性**：
- 弹窗标题动态显示员工姓名
- 弹窗宽度 1000px
- 仅展示，无操作按钮
- 表格分页（每页 10 条）
- 通过 `staffId` 参数筛选数据

### 2. LeaveRecordDrawer.vue（录入调休抽屉）

**功能**：为员工录入调休使用记录

**特性**：
- 自动获取并显示员工的剩余调休时长
- 调休时长校验：不超过剩余调休
- 调休时长范围：0.1-8 小时，步长 0.5
- 调休原因必填，最多 500 字
- 提交成功后刷新主列表

**校验逻辑**：
```typescript
// 计算剩余调休
const remaining = confirmedOvertimeHours - usedLeaveHours;

// 校验调休时长
if (leaveHours > remaining) {
  createMessage.warning(`调休时长不能超过剩余调休 ${remaining.toFixed(1)} 小时`);
  return;
}
```

### 3. OvertimeRecordModal.vue（加班记录弹窗）

**功能**：展示员工的加班记录，支持确认操作

**特性**：
- 弹窗标题动态显示员工姓名和筛选类型
- 弹窗宽度 1300px
- 根据 `confirmStatus` 参数动态显示操作列：
  - 待确认状态：显示"确认"按钮
  - 其他状态：仅展示，无操作
- 确认操作成功后刷新弹窗列表和主列表

**动态列配置**：
```typescript
// 待确认状态显示操作列
if (confirmStatus === '0') {
  columns = overtimeModalColumnsWithAction; // 包含操作列
} else {
  columns = overtimeModalColumns; // 不包含操作列
}
```

## 与加班管理模块的关联

### 数据来源

- 加班记录数据来自 `/overtime/record/list` 接口（加班管理模块）
- 调休统计数据基于加班记录计算：
  - **总调休** = 所有加班时长总和
  - **待确认调休** = 待确认状态的加班时长总和
  - **已确认调休** = 已确认状态的加班时长总和
  - **剩余调休** = 已确认调休 - 已使用调休

### 数据流向

```
加班管理模块                调休统计模块
    │                          │
    ├─ 加班记录 ────────────→ ├─ 加班统计
    │  (overtime/record)       │  (statistics)
    │                          │
    └─ 确认加班 ────────────→ └─ 更新已确认调休
       (confirm)                  (confirmedOvertimeHours)
                                   │
                                   ├─ 录入调休 ─→ 更新已使用调休
                                   │  (addLeave)    (usedLeaveHours)
                                   │
                                   └─ 剩余调休 = 已确认 - 已使用
```

## 使用场景

### 场景 1：管理员查看员工调休统计

1. 打开员工调休统计页面
2. 查看所有员工的调休统计信息
3. 点击统计数字查看详细的加班记录或调休使用记录
4. 为员工录入调休使用记录

### 场景 2：员工查看自己的调休情况

1. 打开"我的加班"页面
2. 页面顶部显示个人调休统计信息
3. 点击"已使用调休"查看自己的调休使用历史

### 场景 3：确认加班后更新统计

1. 在待确认加班记录弹窗中点击"确认"
2. 加班状态变更为已确认
3. 主列表刷新，调休统计信息同步更新（已确认调休增加）
