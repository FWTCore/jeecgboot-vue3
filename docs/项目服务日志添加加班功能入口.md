# 项目服务日志添加加班功能入口

## Context

用户需要在"项目服务日志"(ScheduleLogList)页面添加两个加班功能的入口：
1. **按钮区入口**：在"补录"按钮后面添加"加班"按钮，点击后打开加班记录的新增表单
2. **操作列入口**：在操作列添加"加班"按钮，点击后打开加班记录表单，并自动带入当前行的数据（项目、阶段名称、员工名称、服务方式、加班日期）
3. **保存后跳转**：新增保存成功后，自动跳转到"我的加班"tab

## 代码分析

### 父组件结构 (index.vue)
- 使用 `a-tabs` + `component` 动态切换 tab
- `activeKey` 控制当前显示的组件
- 组件映射关系：`OvertimeRecordList` 对应 key `OvertimeRecordList`

### ScheduleLogList 当前结构
- 按钮区通过 `<template #tableTitle>` 插槽实现
- 操作列通过 `<template #action="{ record }">` 插槽 + `TableAction` 组件实现
- 使用 `useDrawer` 管理抽屉弹窗

### 字段对应关系
| ScheduleLog 字段 | OvertimeRecord 字段 | 说明 |
|-----------------|---------------------|------|
| `projectId` | `projectId` | 项目ID |
| `projectName` | `projectName` | 项目名称 |
| `projectScheduleUsageItemId` | `projectScheduleUsageItemId` | 阶段ID |
| `scheduleName` | `scheduleName` | 阶段名称 |
| `staff` | `staffName` | 员工姓名 |
| `serviceType` | `serviceType` | 服务方式 |
| `createTime` | `overtimeDate` | 日期（服务时间 → 加班日期） |

## 实现方案

### 修改文件列表
1. `src/views/mzx/office/components/project/ScheduleLogList.vue` - 添加加班入口
2. `src/views/mzx/office/components/overtime/OvertimeRecordDrawer.vue` - 支持预填数据和保存后跳转

---

### 一、ScheduleLogList.vue 修改

#### 1. 导入加班抽屉组件
```typescript
import OvertimeRecordDrawer from '../overtime/OvertimeRecordDrawer.vue';
```

#### 2. 定义 emit 用于通知父组件切换 tab
```typescript
const emit = defineEmits(['switchTab']);
```

#### 3. 注册加班抽屉
```typescript
const [registerOvertimeDrawer, { openDrawer: openOvertimeDrawer }] = useDrawer();
```

#### 4. 在模板中添加加班抽屉组件
```vue
<OvertimeRecordDrawer @register="registerOvertimeDrawer" @success="handleOvertimeSuccess" />
```

#### 5. 按钮区添加"加班"按钮
在"补录"按钮后添加：
```vue
<a-button type="primary" preIcon="ant-design:plus-outlined" @click="handleOvertime"> 加班</a-button>
```

#### 6. 添加处理函数
```typescript
// 从按钮区打开加班表单（空白新增）
function handleOvertime() {
  openOvertimeDrawer(true, {
    isUpdate: false,
  });
}

// 从操作列打开加班表单（带入数据）
function handleOvertimeFromRow(record: Recordable) {
  openOvertimeDrawer(true, {
    isUpdate: false,
    record: {
      projectId: record.projectId,
      projectName: record.projectName,
      projectScheduleUsageItemId: record.projectScheduleUsageItemId,
      scheduleName: record.scheduleName,
      staffName: record.staff,
      serviceType: record.serviceType,
      overtimeDate: record.createTime,
    },
  });
}

// 加班保存成功后的回调
function handleOvertimeSuccess() {
  // 通知父组件切换到"我的加班"tab
  emit('switchTab', 'OvertimeRecordList');
}
```

#### 7. 操作列添加"加班"按钮
修改 `getTableAction` 函数，在数组末尾添加：
```typescript
{
  label: '加班',
  onClick: handleOvertimeFromRow.bind(null, record),
},
```

#### 8. 调整操作列宽度
当前宽度 60px，建议调整为 100px 以容纳新按钮。

### 二、OvertimeRecordDrawer.vue 修改

#### 1. 定义 emit 用于通知跳转
```typescript
const emit = defineEmits(['register', 'success']);
```

#### 2. 修改 useDrawerInner 回调逻辑，支持预填充数据
```typescript
const [registerDrawer, { setDrawerProps, closeDrawer }] = useDrawerInner(async (data) => {
  await resetFields();
  setDrawerProps({ confirmLoading: false, showFooter: true });
  isUpdate.value = !!data?.isUpdate;
  immediate.value = false;
  scheduleParams.value = {};

  if (unref(isUpdate)) {
    // 编辑模式：表单赋值
    await setFieldsValue({
      ...data.record,
    });
    if (data.record.projectId) {
      scheduleParams.value = { projectId: toRaw(data.record.projectId) };
      immediate.value = true;
    }
  } else {
    // 新增模式
    const defaultValues = { staffName: userinfo.value.realname };

    // 如果传入了 record，进行预填充（从项目服务日志带入）
    if (data.record) {
      await setFieldsValue({
        ...defaultValues,
        ...data.record,
      });
      if (data.record.projectId) {
        scheduleParams.value = { projectId: toRaw(data.record.projectId) };
        immediate.value = true;
      }
    } else {
      await setFieldsValue(defaultValues);
    }
  }
});
```

### 三、index.vue 修改（父组件）

#### 添加 switchTab 处理函数
```vue
<template>
  ...
  <component :is="currentComponent" @switchTab="handleSwitchTab" />
  ...
</template>

<script>
// 切换 tab
function handleSwitchTab(key: string) {
  activeKey.value = key;
}
</script>
```

**注意**：需要为其他组件（WorkLogList、ServiceLogList、CostLogList）也添加 `@switchTab`，或者只在 ScheduleLogList 上添加即可。

## 验证方式

1. 打开项目服务日志页面，确认"加班"按钮显示在"补录"按钮后面
2. 点击"加班"按钮，确认打开加班表单，员工姓名自动填充当前用户
3. 填写表单并保存，确认自动跳转到"我的加班"tab，且新记录出现在列表中
4. 确认操作列显示"加班"按钮
5. 点击某一行的"加班"按钮，确认表单打开且数据正确带入：
   - 项目名称
   - 阶段名称
   - 员工姓名
   - 服务方式
   - 加班日期（为该行的服务时间）
6. 提交表单后确认自动跳转到"我的加班"tab，数据保存成功
