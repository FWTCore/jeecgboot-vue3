# 项目服务日志工时单位改造设计（前端）

## 1. 需求背景

项目服务日志当前工时字段 `workHours` 单位为**天**，需改为以**小时**为单位录入和展示。

本次改动配合后端改动：
- 后端新增 `workHoursHour` 字段（小时）
- 后端双写 `workHours`（天）供成本核算使用
- 数据库精度调整为3位小数

详见后端设计文档：`jeecg-boot/docs/项目服务日志工时单位改造设计.md`

## 6. 注意事项

### 6.1 历史数据兼容

- 历史数据已通过 SQL 刷数：`work_hours_hour = work_hours * 8`
- 前端展示 `workHoursHour` 字段，历史数据可正常显示

### 6.2 表单校验

- 工时范围限制 0-8 小时（一天最多8小时工时）
- 精度设置为1位小数，支持如 `0.5`、`1.5` 等输入

### 6.3 与后端配合

- 后端接口字段名：`workHoursHour`
- 后端会自动计算 `workHours`（天）并保存
- 前端只需提交 `workHoursHour` 字段
